ETAPA 1 DE 3

Prepare sua Database no Notion

Antes de configurar seu VisualFeed, você precisa criar uma Database com as propriedades que o feed utiliza para organizar e exibir seus posts. Siga este guia com calma.

Você vai precisar Uma conta no Notion

Use o workspace em que deseja manter seus posts.

O objetivo Uma Database pronta

Ela será a fonte de conteúdo do seu VisualFeed.

1. Crie sua Database

  1. Acesse o Notion e entre na sua conta.
  2. Abra o workspace em que deseja organizar os posts.
  3. Crie uma página nova para o seu feed.
  4. Dentro da página, crie uma Database no formato de tabela. Você pode usar a opção de tabela em linha ou uma tabela em página inteira.
  5. Dê um nome fácil de reconhecer, como Posts do VisualFeed.
Importante: o VisualFeed lê os dados da Database. Criar apenas uma tabela comum, sem as propriedades abaixo, não é suficiente.

2. Configure as propriedades

Agora, organize as colunas da sua Database. Os nomes e tipos abaixo devem corresponder aos campos que o VisualFeed utiliza.

Tipo no Notion Nome da propriedade Para que serve
Título Post Nome ou título do post. Renomeie a propriedade de título padrão para “Post”.
Caixa de seleção Ocultar Visualização Permite ocultar um post do feed quando marcada.
Data Data de Publicação Data associada ao post.
Arquivos e mídia Mídia Permite adicionar arquivos de imagem ou vídeo.
URL Link da Mídia Campo alternativo para um link externo de mídia.
Selecionar Editoria Categoria ou tema do post.
Arquivos e mídia Capa do Vídeo Imagem de capa para vídeos, quando aplicável.
URL Design Incorporado Link de um design incorporável, como um projeto do Canva.
Selecionar Formato Identifica o formato do conteúdo.
Número Fixado Define a posição de um post fixado no feed.

Como criar ou alterar uma propriedade

  1. Na tabela, clique no nome de uma coluna.
  2. Escolha a opção para editar ou alterar o tipo da propriedade, quando necessário.
  3. Para criar uma nova coluna, use o botão de adicionar propriedade.
  4. Digite o nome exatamente como aparece na tabela acima e selecione o tipo correspondente.
  5. Repita até configurar todas as propriedades.
Atenção aos nomes: respeite os espaços e a grafia indicados neste guia. Evite criar duas propriedades com a mesma função.

3. Configure as opções de seleção

Nas propriedades do tipo Selecionar, você pode criar opções para organizar seus conteúdos.

Na propriedade “Formato”

Crie as opções que correspondem aos formatos que pretende usar:

  • Imagem
  • Vídeo
  • Carrossel
  • Reels

Na propriedade “Editoria”

Adicione as categorias que fizerem sentido para seu conteúdo. Por exemplo: Bastidores, Educativo, Institucional ou Dicas.

As opções de Editoria são exemplos. Personalize-as de acordo com a organização dos seus posts.

4. Entenda os campos de mídia

  • Mídia: use para adicionar um arquivo diretamente à Database.
  • Link da Mídia: campo alternativo para informar um endereço externo de mídia.
  • Capa do Vídeo: use quando precisar associar uma imagem de capa ao vídeo.
  • Design Incorporado: use para informar o link de um design que possa ser incorporado, como um design do Canva.

Os campos de link e de incorporação são opcionais. Preencha-os conforme o tipo de conteúdo que deseja exibir.

5. Confira antes de continuar

Revise sua Database e confirme se você:

  • Criou uma Database no Notion.
  • Configurou as dez propriedades indicadas.
  • Conferiu os nomes e os tipos das propriedades.
  • Adicionou as opções desejadas em “Formato”.
  • Salvou a página no workspace correto.
