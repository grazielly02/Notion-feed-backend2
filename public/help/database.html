ETAPA 1 DE 3

Prepare sua Database

A Database será a fonte de conteúdo do seu VisualFeed. Prepare essa estrutura no Notion antes de seguir para a integração.

01

Crie sua Database

Comece criando a base onde seus posts ficarão organizados.

1
Abra o Notion

Acesse sua conta e entre no workspace onde deseja usar o VisualFeed.

2
Crie uma nova página

Essa página será o espaço onde sua Database ficará armazenada.

3
Adicione uma Database

Crie uma tabela no Notion para organizar os conteúdos do seu feed.

4
Dê um nome para sua Database

Escolha um nome fácil de identificar, como “Posts do VisualFeed”.

02

Adicione as propriedades

Essas são as informações que o VisualFeed utiliza para montar seu conteúdo.

TÍTULO Post

Nome ou título do conteúdo.

CAIXA DE SELEÇÃO Ocultar Visualização

Oculta o post do VisualFeed quando marcada.

DATA Data de Publicação

Data associada ao conteúdo.

ARQUIVOS E MÍDIA Mídia

Imagens ou vídeos utilizados no post.

URL Link da Mídia

Link externo de uma mídia, quando necessário.

SELECIONAR Editoria

Categoria ou tema do conteúdo.

ARQUIVOS E MÍDIA Capa do Vídeo

Imagem utilizada como capa de um vídeo.

URL Design Incorporado

Link de um design que será incorporado ao conteúdo.

SELECIONAR Formato

Define o formato do conteúdo.

NÚMERO Fixado

Define a posição de um conteúdo fixado.

Dica: crie os nomes exatamente como aparecem acima. Isso ajuda o VisualFeed a reconhecer cada informação corretamente.
03

Deixe tudo pronto

Uma última conferência antes de conectar o Notion.

✓ Database criada no Notion
✓ As propriedades foram adicionadas
✓ Os nomes das propriedades foram conferidos
✓ A Database está no workspace correto
Database pronta?

Agora vamos conectar seu Notion.

Na próxima etapa, você vai criar a integração, obter seu token secreto e permitir o acesso à Database.
