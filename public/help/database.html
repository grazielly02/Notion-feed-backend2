PRIMEIRO PASSO

Prepare sua Database no Notion

Antes de conectar o VisualFeed, vamos preparar a Database que alimentará o seu feed.

01 · DATABASE

Crie sua Database no Notion

Se você ainda não possui uma Database para o VisualFeed, siga estes passos para criar a estrutura onde seus conteúdos ficarão armazenados.

1

Abra o Notion

Acesse sua conta do Notion e entre no workspace onde deseja utilizar o VisualFeed.

2

Crie uma nova página

Crie uma página para organizar os conteúdos que serão exibidos no seu feed.

3

Adicione uma Database

Dentro da página, adicione uma Base de dados - in-line. É nela que ficarão seus conteúdos.

4

Dê um nome para ela

Escolha um nome que facilite sua identificação, como VisualFeed ou Conteúdos.

02 · PROPRIEDADES

Configure os campos da sua Database

Agora vamos configurar as propriedades que serão utilizadas pelo VisualFeed para organizar e exibir seus conteúdos.

Nome da propriedade O nome que você dá ao campo

É o texto que identifica aquela informação dentro da sua Database.

Exemplo: Mídia
Tipo da propriedade O tipo de informação que o campo aceita

Define como aquela informação será preenchida no Notion.

Exemplo: Arquivos e mídia

Ao criar cada propriedade, use exatamente o nome indicado e selecione o tipo correspondente.

ESSENCIAL

Para o conteúdo aparecer

Esta propriedade é necessária para que o conteúdo visual seja exibido no feed.

Nome da propriedade
Tipo da propriedade
Mídia Imagem ou mídia principal do conteúdo.
Arquivos e mídia
RECOMENDADO

Para organizar melhor o feed

Não são indispensáveis para renderizar um conteúdo, mas deixam o feed mais completo e organizado.

Nome da propriedade

Data
Como a data funciona: os conteúdos com data aparecem primeiro, do mais recente para o mais antigo. Conteúdos sem data ficam no final do feed.
