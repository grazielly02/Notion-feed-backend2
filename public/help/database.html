Prepare sua Database no Notion

Antes de conectar o VisualFeed, vamos preparar a Database que alimentará o seu feed. É nela que você vai cadastrar os conteúdos que deseja exibir.

01 • Começando pelo princípio

Primeiro, crie sua Database

Se você ainda não possui uma Database para o VisualFeed, siga estes passos no Notion.

1

Abra o Notion

Acesse sua conta e entre no workspace onde deseja utilizar o VisualFeed.

2

Crie uma nova página

Crie uma página para organizar os conteúdos que serão exibidos no seu feed.

3

Adicione uma Database

Dentro da página, adicione uma Database em formato de tabela. É nela que ficarão os seus conteúdos.

4

Dê um nome para ela

Escolha um nome que facilite sua identificação, como VisualFeed ou Conteúdos.

02 • Estrutura

Configure as propriedades

As propriedades são os campos da sua Database. Elas determinam quais informações você poderá cadastrar em cada conteúdo.

Você não precisa criar todos os campos abaixo. Comece pelo essencial e adicione os recursos recomendados ou opcionais conforme a forma como pretende usar o VisualFeed.
Essencial

Para o conteúdo aparecer

Esta propriedade é necessária para que o conteúdo visual seja exibido no feed.

Mídia Imagem ou mídia principal do conteúdo.
Arquivos e mídia
Recomendado

Para organizar melhor o feed

Não são indispensáveis para renderizar um conteúdo, mas deixam o feed mais completo e organizado.

Post Nome ou título do conteúdo.
Título
Data de Publicação Define a ordem de exibição dos conteúdos.
Data
Como a data funciona: conteúdos com data aparecem primeiro, do mais recente para o mais antigo. Conteúdos sem data ficam no final do feed.
Opcional

Recursos adicionais

Adicione somente os recursos que fizerem sentido para o seu uso.
