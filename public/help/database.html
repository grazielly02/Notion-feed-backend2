PRIMEIRO PASSO

Prepare sua Database

Sua Database será a fonte de conteúdo do VisualFeed. Prepare-a no Notion antes de continuar.

01
ESSENCIAL

Mídia

É o conteúdo visual que será exibido no VisualFeed.

ARQUIVOS E MÍDIA Mídia

Adicione as imagens ou vídeos que deseja exibir no seu feed. Também é possível utilizar mídias externas quando aplicável.

Importante: cada conteúdo que você quiser exibir no VisualFeed precisa ter uma mídia associada.
02
RECOMENDADO

Organize seus conteúdos

Esses campos ajudam a deixar seu feed mais completo e organizado.

TÍTULO RECOMENDADO
Post

Nome ou título que identifica o conteúdo no VisualFeed.

DATA RECOMENDADO
Data de Publicação

Define a ordem dos conteúdos no feed. Os posts mais recentes aparecem primeiro e os posts sem data ficam no final.

03
RECURSOS OPCIONAIS

Escolha o que você quer usar

Adicione somente os recursos que fizerem sentido para o seu conteúdo.

CAIXA DE SELEÇÃO Ocultar Visualização

Esconde um conteúdo do VisualFeed sem precisar removê-lo da Database.

SELECIONAR Editoria

Organiza os conteúdos por categoria ou tema.

SELECIONAR Formato

Identifica o tipo de conteúdo, como imagem, vídeo, carrossel ou reels.

NÚMERO Fixado

Permite posicionar conteúdos em áreas de destaque do feed.

ARQUIVOS E MÍDIA Capa do Vídeo

Define a imagem de capa exibida para um vídeo.

URL Link da Mídia

Permite fornecer uma mídia por meio de um link externo.

URL Design Incorporado

Permite incorporar designs externos, como conteúdos do Canva ou Figma.

Dica: crie os nomes das propriedades exatamente como aparecem acima. Assim, o VisualFeed consegue reconhecer cada informação corretamente.
04
NO NOTION

Crie sua Database

Agora monte essa estrutura dentro do workspace onde você usará o VisualFeed.

1
Abra o Notion

Acesse o workspace onde deseja utilizar o VisualFeed.

2
Crie uma nova página

Essa página será o espaço onde sua Database ficará armazenada.

3
Adicione uma base de dados in-line

Crie uma Database para organizar os conteúdos que serão exibidos no feed.

4
Configure as propriedades

Crie os campos essenciais e recomendados e adicione os recursos opcionais que desejar utilizar.

5
Dê um nome para sua Database

Escolha um nome que facilite a identificação da sua base no Notion.

05
CONFERÊNCIA

Antes de continuar

Faça uma última conferência na sua Database.
