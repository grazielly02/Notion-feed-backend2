01 · CHECKLIST

Confira se está tudo preparado

Antes de entrar na configuração, confirme se você concluiu as etapas anteriores e tem tudo o que precisará para configurar seu VisualFeed.

Você já deve ter:

  • ✓ A Database criada e preparada no Notion.
  • ✓ A conexão VISUALFEED criada.
  • ✓ O Token de API copiado.
  • ✓ O link da visualização da Database copiado.

Está com tudo isso em mãos? Então você já pode seguir para a validação da sua compra.

02 · VALIDAÇÃO

Valide sua compra

Para continuar para a configuração do VisualFeed, você precisará validar o acesso utilizando o mesmo e-mail informado no momento da compra.

Use o mesmo e-mail da compra

É por meio dele que o VisualFeed identifica sua licença e libera o acesso à configuração.

Se o e-mail não for reconhecido, confira se você está utilizando o mesmo e-mail informado na compra.

03 · CONFIGURAÇÃO

Continue para a configuração

Depois de validar sua compra, você poderá informar os dados necessários para conectar sua Database ao VisualFeed e configurar seu widget.

01
Nome

O nome que você deseja utilizar para identificar seu VisualFeed.

02
Token

O token da conexão VISUALFEED criada no Notion.

03
Link da Database

O link da visualização da Database preparada no Notion.

Próxima etapa

Após a validação, você poderá preencher os dados da sua configuração e seguir para a visualização do seu widget.
