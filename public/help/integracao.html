SEGUNDO PASSO

Conecte o Notion ao VisualFeed

Agora vamos criar uma conexão no Notion, gerar seu token de API e conectá-la à página que contém a Database preparada no primeiro passo.

01 · CONEXÃO

Crie uma conexão no Notion

Primeiro, vamos criar a conexão que permitirá ao VisualFeed acessar a Database que você preparou.

Antes de começar

Verifique se você está conectado ao Notion com a conta que possui o workspace onde sua Database foi criada. Se as ferramentas de desenvolvedor não aparecerem no celular, abra este endereço pelo navegador ou pelo computador.

Abrir ferramentas do desenvolvedor ↗
1

Abra as ferramentas do desenvolvedor

Clique no botão acima para abrir diretamente a área de conexões do Notion.

2

Clique em + Nova conexão

Na página que abrir, clique no botão azul + Nova conexão.

3

Dê o nome VISUALFEED

No campo de nome da conexão, informe VISUALFEED.

4

Selecione Token de API

Na opção de tipo de conexão, selecione Token de API e conclua a criação.

Nome da conexão VISUALFEED

Use esse nome para identificar facilmente a conexão quando for adicioná-la à página da sua Database.

Workspace Selecione o workspace correto

Se o Notion pedir para escolher um workspace, selecione aquele onde sua Database do VisualFeed está localizada.

02 · TOKEN DE API

Copie o token da conexão

Depois de criar a conexão, o Notion abrirá a página de informações dela. É lá que está o token que você usará no VisualFeed.

1

Localize o bloco Token de integração

Na página de informações da conexão, procure o bloco chamado Token de integração.

2

Localize o Token de API

Nesse bloco estará disponível o Token de API da conexão.

3

Copie o token

Copie o token completo e mantenha-o em um local seguro.

Importante: o token é uma credencial secreta. Não compartilhe esse código com outras pessoas. Você precisará dele no painel do VisualFeed.

03 · CONEXÃO

Adicione a conexão à página da sua Database

Criar a conexão não dá acesso automático a todas as suas páginas. Agora você precisa adicioná-la à página que contém a Database que preparou.

1

Volte para a página da Database

Abra no Notion a página que contém a Database que você preparou no primeiro passo.

2

Abra o menu de opções •••

No canto superior direito da página, clique no botão ••• para abrir o menu de opções.

3

Acesse Conexões

No menu, selecione Conexões e depois + Adicionar conexão.

4

Selecione VISUALFEED

Procure pela conexão VISUALFEED e confirme.

O que estamos fazendo Autorizando o acesso

Você está permitindo que a conexão VISUALFEED acesse os conteúdos dessa página e da Database que ela contém.

Atenção Use a página da Database preparada

Certifique-se de estar na página que contém a mesma Database preparada no primeiro passo.

04 · LINK DA DATABASE

Copie o link da sua Database

Por último, copie o link da visualização da Database. Você usará esse link na configuração do VisualFeed.

1

Abra sua Database

Acesse a Database que você preparou no primeiro passo.

2

Abra as configurações da Database

Na parte superior da Database, clique no ícone de configurações.

3

Selecione Copiar link para a visualização

No menu de configurações, selecione Copiar link para a visualização.

O que você deve copiar Link da visualização da Database
https://app.notion.com/p/seu-workspace/sua-database?v=...&source=copy_link

Não precisa extrair o ID. Basta copiar o link completo. O VisualFeed identifica as informações necessárias automaticamente.

Antes de continuar, confira se você tem:

  • ✓ A conexão VISUALFEED criada.
  • ✓ O Token de API copiado.
  • ✓ A conexão VISUALFEED adicionada à página que contém sua Database.
  • ✓ O link da visualização da Database copiado.

Tudo certo? Então você está pronto para seguir para o painel e continuar a configuração do VisualFeed.
